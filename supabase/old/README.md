# Old combined files (do not use)

These two files were shortcuts made earlier, when updates were run a few at a time:

- `ALL-UPDATES.sql` (updates 1 to 4)
- `update-14-to-18-ALL.sql` (updates 14 to 18)

They have been replaced by **`../INSTALL-ALL.sql`**, which holds every update, in order.
Running one of these old files now could put back older versions of some functions.
They are kept only as a record.
